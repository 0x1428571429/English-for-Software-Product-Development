# Web Trainer QA 手册

> 最后更新：2026-11-05 · 适用版本：v1.0.1

这份文档记录**每次发布前怎么测、测什么、哪些是已知限制**。下次继续测试时，从「快速开始」和「功能清单」往下走，把当次结果追加到「测试记录」。

---

## 快速开始

```bash
cd web
npm ci                 # 首次或依赖变更后
npm run dev -- --host 127.0.0.1 --port 5173
```

- 端口被占用时 Vite 会自动递增（例如 5174），以启动日志为准。
- **QA 用独立数据**：Playwright 隔离上下文 / 浏览器隐私窗口，不要用日常浏览器的配置。
- **破坏性测试先导出**：清空全部数据、导入覆盖之前，先在设置页导出 JSON。
- Edge TTS 需要本地代理：

```bash
npm run tts:proxy      # 另一个终端
```

设置页的「Edge 代理地址」填 `http://127.0.0.1:8787`。上游 429 时代理会返回 502，应用回退百度音频属于预期行为，控制台出现 502 不算失败。

### 发布前自动检查

```bash
npm run typecheck
npm test               # 70 项（v1.0.1 时）
npm run build
npm run lint           # 只允许既有 warning
```

### 生产 / PWA 验证

```bash
npm run build
npm run preview        # 端口被占用时自动递增，看启动日志
```

用独立浏览器上下文打开 preview：

1. `navigator.serviceWorker.ready` 且 `controller` 存在。
2. `manifest.webmanifest` 可访问，`start_url` 为 `./`，图标 4 个。
3. 断网后刷新首页仍渲染；切到 `#/library/01-daily-standup` 仍有内容。
4. 资源引用是 `./assets/...` 相对路径。

## 功能清单

### 1. 反射训练 `/drill`

- [ ] 开始一组：卡片出现，倒计时正常。
- [ ] 超时：自动揭示并标记，仍可自评。
- [ ] 输入答案：正确/近似/错误都能判定并显示差异。
- [ ] 自评 1–4：进入下一张，结算页数据合理。
- [ ] 刷新后：进度与 due 状态保留。
- [ ] 键盘：`Space` 揭示、`1–4` 评分、`R` 重播、`S` 跳过、`?` 快捷键。

### 2. 打字 `/typing`

- [ ] 填字模式：首字母提示、错误反馈、逐空校验、评分。
- [ ] 整句模式：逐词差异高亮、评分。
- [ ] 音效：每次按键 down/up 各响一次；训练页右上角可快速静音。
- [ ] 设置页切换音效包后立刻生效；4 套音效均可试听。
- [ ] 只在输入框发声，点击其他区域不响。

> 开发模式下 HMR 可能残留旧监听，出现「一次按键响 4 声」时先整页刷新再判断。

### 3. 场景 `/scenario`

- [ ] 选择后显示对错、解析、替代表达。
- [ ] 下一题推进，进度正确。
- [ ] **点击选项后鼠标停留在原地，不弹出查词卡片**（400ms 抑制）。
- [ ] 鼠标移动后重新悬停英文，查词仍正常。

### 4. 对话 `/dialogue/:id`

- [ ] 「显示中文」开关生效。
- [ ] 角色扮演：选择自己的角色后己方台词隐藏，逐句揭示。
- [ ] 整段播放按行排队，行间有停顿。
- [ ] 聊天格式（10-slack-im）与 User/Dev 格式（15-user-guidance）渲染正常。
- [ ] 无翻译的行显示「暂无翻译」，不阻塞角色扮演。

### 5. 听力 `/listen`

- [ ] 点击播放有声音；在线引擎失败时回退百度/系统音色。
- [ ] 听写模糊匹配正确；揭示后显示原文与中文。
- [ ] 发音页单词优先词典发音，失败回退所选引擎。

### 6. 语料库 `/library`

- [ ] 搜索表达/单词能命中。
- [ ] 章节详情分栏切换正常。
- [ ] 卡片数与语料统计一致（v1.0.1：1383 张卡 / 699 句对话 / 218 个表达 / 232 个词汇）。

### 7. 全局查词（任意页面）

- [ ] 悬停英文约 0.28s 出卡片，命中词有 tag 高亮。
- [ ] 双击固定卡片，显示「已固定」；`Esc` 关闭。
- [ ] 收藏、改颜色（重点/已掌握/易错）后生词本同步。
- [ ] **固定卡片后点击导航切路由，卡片必须消失**。
- [ ] 点击按钮/选项后 400ms 内不因鼠标停留误弹。
- [ ] 移动端：点按单词打开、点按钮关闭，卡片不超出 390px 视口。
- [ ] 滚动或缩放时卡片收起。

### 8. 生词本 `/words`

- [ ] 颜色筛选、类型筛选正确。
- [ ] 卡片上改颜色、删除收藏立即生效。
- [ ] 刷新后颜色与收藏状态保留。
- [ ] 空态文案与「去剧情模式」入口正常。

### 9. 职场 `/career`

- [ ] 未通关知识卡显示锁定与解锁条件；通关后解锁。
- [ ] 汇报训练：切换场景、填入示例、朗读、复制英文。
- [ ] 剪贴板内容为四段式英文骨架（BLUF/Incident/STAR/SCQA）。

### 10. 剧情 `/story`

- [ ] 首次进入选择前端/全栈路径；进入专精线后切换被锁定。
- [ ] 剧集锁定条件（职级/绩效点/前置集/路径）提示正确。
- [ ] 空格/Enter 推进；打字机未完成时第一次按键只跳过。
- [ ] 选择后有「好选择/还行/有风险」反馈，信任值变化。
- [ ] 结局页显示好选择数、绩效、挑战是否通过；首通 +20，挑战通过再 +20。
- [ ] 回剧情大厅后「已通关」「最佳 x/4」与绩效点保留；刷新后仍在。
- [ ] 重玩不重复刷分。
- [ ] **已知限制 R-20**：单集中途刷新会回到本集开头（选择、信任值不保留）。

### 11. 统计 `/stats`

- [ ] 空数据不崩，有引导文案。
- [ ] 热力图、复习量、反应时间、章节掌握度在有数据后正常渲染。
- [ ] 弱项/连续天数与训练记录一致。

### 12. 设置 `/settings`

- [ ] 训练节奏：每日目标、新卡上限、每组卡片数、限时选项保存并在刷新后保留。
- [ ] 发音引擎：自动 / Edge / 百度 / Google / 系统；口音与音色选项联动。
- [ ] 试听：Edge、百度、Google、系统都能触发；失败有回退。
- [ ] 「重新检测」不会报错。
- [ ] 4 个开关：滑块 18×18，始终在 44×24 轨道内（开/关都检查）。
- [ ] 打字音效：开关、4 套音效、音量、试听。
- [ ] 导出：下载 `blurt-backup-YYYY-MM-DD.json`，提示成功。
- [ ] 清空：第一次点击变「再点一次确认清空」，第二次清空；生词本变为 0。
- [ ] 导入：确认弹窗后恢复 progress/settings/story/favorites，提示已导入模块。
- [ ] 存储统计、语料版本显示正常。

### 13. 发布 / 线上

- [ ] PR 合并后确认 Pages workflow 成功（`gh run list`）。
- [ ] 线上 `index.html` 引用新的 asset hash。
- [ ] 线上抽查：设置页开关几何、固定查词卡随导航关闭。
- [ ] Release 指向本次合并的 commit，正文无内部工具署名。

## 回归注意（改这些地方必须重测）

| 区域 | 约束 |
|---|---|
| 查词触发 | 悬停 280ms 出卡、移出 220ms 收起；`pointerdown` 后 400ms 抑制 hover；路由变化用 key 重挂载；触屏用 `pointerup` 打开、点按钮关闭 |
| 开关组件 | 轨道 44×24，滑块 18×18，`left-0.5`，开启 `translate-x-5`；关闭时 `translate-x-0` |
| 打字音效 | 只在输入框播放；down/up 双采样；HMR 残留监听要用整页刷新排除 |
| TTS | 在线引擎失败必须回退；Edge 需要本地代理；不要把 token 打印到日志 |
| 备份 | `efspd-backup / formatVersion 1`；各模块独立版本；导入未知模块跳过而不是报错 |
| 剧情记录 | 通关记录、绩效点、认知、路径选择必须持久化；重玩不重复加分 |
