## "I didn't think of that. Good catch."

QA 提到了你没想到的 case。

Also say：
- Good catch — 好发现
- I missed that — 我漏了
- Thanks, I'll add it
- That's a valid scenario

### QA 说"太低了"

> C: Rare doesn't mean it won't happen. If it happens, the user gets charged twice.
> B: Fine. I'll add it.

- Rare doesn't mean it won't happen — 概率低不代表不会发生
- If it happens, it breaks everything — 发生了就全完了
- It's low probability but high impact
- Better to cover it now

### 测试优先级

> B: Let me prioritize the critical path tests first.

- Critical path first — 关键路径优先
- Focus on the core flow
- Edge cases can wait
- We'll test the happy path first

### When to use

- QA 发现你漏了 case 时
- 需要排测试优先级时
- QA 说"这个概率太低"时
