### "Yeah, I'll add it"
QA 说漏了 case。立即加。
还可以说：
- Good catch, I'll add it
- Missed that one. Let me update the tests.
- Thanks, I'll cover that too.

### "That's an edge case, we can handle later"
QA 提的 case 概率太低。
还可以说：
- That's a low probability scenario
- We can deal with it if it happens
- Let's focus on the critical path first
- We'll add it in the next iteration
