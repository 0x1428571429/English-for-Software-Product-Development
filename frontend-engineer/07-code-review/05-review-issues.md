### "Here's why I did it this way"
解释 PR。
还可以说：
- The reason I did it this way is...
- I chose this approach because...
- Let me explain the tradeoffs
- There's a context behind this decision

### "You should use X instead of Y"
有人说你写法不对。
还可以说：
- There's a better way to do this
- Have you considered X?
- The team convention is to use X
- I'd prefer if you used X

### "This PR has been through 10 rounds of review"
review 了十轮还没合并。
还可以说：
- We've been going back and forth for weeks
- Can we agree and move on?
- This is getting too nitpicky
- Let's just merge it and iterate
