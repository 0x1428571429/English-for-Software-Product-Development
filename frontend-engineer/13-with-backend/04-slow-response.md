### "It takes 8 seconds for a simple query"

接口响应太慢。

还可以说：
- The API is too slow
- Response time is unacceptable
- This blocks the UI — users will leave
- Can we add caching?

### "The database is under load"

后端各种慢的原因。

还可以说：
- We're adding indexes
- The query needs optimization
- Too many requests hitting the DB
- Need to cache the response

### "That's a frontend decision"

后端把球踢给前端。

还可以说：
- Do what you need on your end
- You can handle that on the frontend
- That's not a backend issue
- Add a timeout on your side
