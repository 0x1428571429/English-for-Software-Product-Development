## "I'm blocked on the API doc. Haven't heard from the backend team."

被 block 了，但催人的方式也不对，对方根本没 notice。

### 还可以说

- Blocked on the API doc from backend
- Waiting on the backend team
- Can't move forward until I get the API format

### 催了但没催到位

> D: I pinged them yesterday.
> A: Did you @ them?
> D: ...no.

发消息没 @ 人，对方可能没看到：
- I sent a message in the channel — 我在频道发了
- I didn't @ them directly — 没 @ 他们
- I should probably ping them directly — 我应该直接找他们

### 正确的催法

- @ them in Slack — @ 他们
- Send a DM — 发私信
- Ping them in the standup channel — 在站会频道 @

### 让别人同步进度

> A: Alright. Keep me posted.

- Keep me posted — 有进展告诉我
- Let me know when you hear back
- Update me when you have something

### 各种 blocker

| 情况 | 怎么说 |
|------|--------|
| 等接口文档 | Waiting on the API doc |
| 等后端修 bug | Blocked on a backend fix |
| 等 review | PR is up, waiting for review |
| 环境挂了 | Staging is down |

### 什么时候说

- 等待别人时
- 催人但没回应时
- 被问到有没有跟进时
