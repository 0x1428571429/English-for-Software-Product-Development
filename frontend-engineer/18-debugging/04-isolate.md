### "Let me check the git log"

排查第一步 — 看谁改了什么。

还可以说：
- Let me see what changed recently
- Check the latest commits
- Let me blame this line
- Who merged last night?

### "Let me comment out the new code and test"

二分法排查。

还可以说：
- Let me isolate the issue
- Let me revert one change at a time
- Let me narrow it down
- Let me test without the new code
