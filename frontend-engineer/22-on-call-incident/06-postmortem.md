### "Let me write up a postmortem"

事后复盘。

还可以说：
- We need to document what happened
- Let's schedule a postmortem
- Root cause analysis
- Let's review it with the team

### "The hotfix has a memory leak"

紧急修复的代码有问题。

还可以说：
- The hotfix introduced a regression
- The fix caused more issues
- We need a proper fix, not a hotfix
- Hotfix broke something else
