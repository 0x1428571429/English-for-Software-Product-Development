### "I'm already at capacity"
活太多了接不了。

还可以说：
- I don't have bandwidth
- My plate is full
- I'm already overcommitted
- I can't take anything else

### "I've never done this before"
新人没做过，需要指导。

还可以说：
- I'll need help
- Can someone guide me?
- I don't have experience with this
- I can learn but it'll take time

### "Can you pair with X?"
安排老人带新人。

还可以说：
- Can you help X get started?
- Can you be the point person for X?
- X needs a mentor on this
- Can you review X's work?

### "It's higher priority"
紧急打断。

还可以说：
- This takes precedence
- Drop what you're doing
- This is urgent
- Push your current task
