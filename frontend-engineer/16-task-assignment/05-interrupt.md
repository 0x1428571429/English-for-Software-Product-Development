### "It's higher priority. Drop what you're doing."

紧急打断。

还可以说：
- This takes precedence
- Stop your current task
- This is urgent
- Push your other work

### "When does it need to be done by?"

接受任务但问 deadline。

还可以说：
- What's the deadline?
- How urgent is this?
- When do you need it?
- Is there a hard deadline?
