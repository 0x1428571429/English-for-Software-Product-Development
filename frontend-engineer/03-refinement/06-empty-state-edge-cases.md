## "What about the empty state? What do we show when there's no results?"

开发想到的边界情况 PM 没考虑。

还可以说：
- What about the loading state?
- What about error handling?
- What about when the API fails?
- What about slow network?

### 关联对话

> D: What about the empty state? What do we show when there's no results?
> B: I didn't think about that. What do you suggest?
> D: We need a design for that. I'll ask the designer.

PM 没想过：
- I didn't think about that — 我没想到
- What do you suggest? — 你觉得呢？
- Good question — 好问题

### "One more thing"

> B: One more thing — can we make it work on the old browser version too?

PM 的"还有一件事"：
- One more thing... — 还有一件...
- Also, can we... — 另外...
- While you're at it... — 顺便...

挡住：
- That's a separate conversation
- Let's keep the scope focused
- Let's ship the basic version first
- We can do that later

### 什么时候说

- PM 没考虑加载/空/错误状态时
- PM 不断追加需求时
- 需要保护 sprint scope 时
