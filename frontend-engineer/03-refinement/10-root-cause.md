### "The real issue is B, not A"

被要求做 A，但其实 B 才是关键。

还可以说：
- That's treating the symptom, not the problem
- The root cause is something else
- We're solving the wrong problem
- A is a band-aid fix. The real problem is B

### "We can't do this until X is done"

有前置依赖。

还可以说：
- X is a dependency
- We're blocked on X
- We need X first
- Can't start until X is finished
