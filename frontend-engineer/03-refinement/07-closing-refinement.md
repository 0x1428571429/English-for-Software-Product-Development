## "OK, so scope for this sprint: search by name and category. No price range. No autocomplete. Clear?"

最终确认 scope，让所有人都同意。

还可以说：
- Let's confirm what we're doing
- So we agree on X, Y, and Z?
- Anyone disagree?
- Let's lock the scope

### 关联对话

> A: OK, so scope for this sprint: search by name and category. No price range. No autocomplete. Clear?
> B: I guess.
> C: Good. Finally.

PM 妥协：
- I guess — 好吧（不太情愿）
- Fine — 行吧
- If that's all we can do — 如果只能这样

### 什么时候说

- 需求评审结束时
- 确认 scope 避免后面扯皮
- PM 不太情愿但接受了
