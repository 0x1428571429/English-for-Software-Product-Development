## "What problem are we solving here?"

需求讨论跑偏了，拉回来问本质。

还可以说：
- Let's step back
- What's the user need here?
- Why are we building this?
- What's the actual goal?

### 关联对话

> A: Let's step back. What problem are we solving here?
> B: Users can't find products.
> A: OK, so what's the simplest thing that solves that?
> B: Search by name.
> A: Then let's start there. We can iterate.

找到最简单的方案：

- What's the simplest thing that solves that?
- Let's start there
- We can iterate
- Ship the basic version first
- We can polish later

### "We can iterate"

- Let's ship the basic version first
- We can always add more later
- MVP first, then enhance
- Perfect is the enemy of done

### 什么时候说

- 需求越来越复杂时
- 讨论跑偏了需要拉回来时
- 需要找到最小可行方案时
