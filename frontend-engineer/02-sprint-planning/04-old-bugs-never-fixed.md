## "We still have 5 open bugs from the last release that nobody touched."

老 bug 没人修，又塞新的。

还可以说：
- We have unresolved bugs from last sprint
- These bugs keep getting pushed
- The bug backlog is growing
- Nobody's touched those bugs

### 关联对话

> A: PM, are those bugs in scope for next sprint?
> B: They're not critical. We can push them.
> C: We keep pushing them. They're not going away.

PM 说"不紧急，先推"：
- They're not critical — 不紧急
- We can push them — 可以推
- Let's deal with them later — 以后再说

反问 PM：
- They're not going away — 它们不会自己消失
- When will we fix them?
- At what point do they become critical?
- We're accruing technical debt

### 什么时候说

- sprint planning 里有新需求也有旧 bug
- PM 一直推 bug 不修
- 开发觉得 bug 优先级太低不合理
