# High Frequency Expressions — 高频表达汇总

> 各场景常用表达到底怎么说。一句话的答案。

## 进度相关

| 意思 | 日常说法 |
|------|---------|
| 还没做完 | Still on it |
| 快做完了 | Almost there |
| 做完了 | Done / Wrapped up |
| 今天继续 | Picking it back up today |
| 请假回来 | I was out yesterday, catching up |
| 比预想难 | This one's a rabbit hole |
| 低估了 | I underestimated this |
| 卡住了 | I'm stuck on X |
| 需要帮助 | I could use some help with X |

## Block / 依赖别人

| 意思 | 日常说法 |
|------|---------|
| 在等别人 | Waiting on the backend team |
| 被block了 | Blocked on the API doc |
| 催一下 | I'll nudge them again |
| 有进展告诉我 | Keep me posted |
| 我查一下 | Let me check |
| 回头告诉你 | I'll get back to you |

## PR / Review

| 意思 | 日常说法 |
|------|---------|
| PR提了 | PR is up |
| 等review | Waiting for review |
| 小问题 | It's a nit |
| 通过了 | LGTM |
| 我不太确定 | I'm not 100% sure |
| 帮我看看 | Can you take a look? |

## 会议/讨论

| 意思 | 日常说法 |
|------|---------|
| 会后聊 | Let's take this offline |
| 回头再说 | Let's circle back |
| 长话短说 | TL;DR |
| 拉回正题 | Moving on |
| 插句话 | Can I jump in? |
| 你继续说 | Go ahead |
| 我没听懂 | I'm not following |
| 再说一遍 | Say that again? / Come again? |

## 拒绝/反驳

| 意思 | 日常说法 |
|------|---------|
| 做不完 | We can't fit all of this |
| 不在范围内 | That's not in scope |
| 你有优先级的 | Pick one |
| 我不同意 | I see it differently |
| 太复杂了 | That's over-engineered |
| 砍需求 | Let's cut scope |

## AI 相关

| 意思 | 日常说法 |
|------|---------|
| AI写了大部分 | AI wrote most of it |
| AI搞砸了 | AI created more problems than it solved |
| AI的方案不行 | AI suggested something but it didn't work |
| 让AI做了原型 | I had AI prototype it |
| 先问AI | Try AI first |
| AI说是这个原因 | AI says it's a config issue |
