# Common Mistakes — 常见中式错误汇总

> 这是从所有章节中提取的常见错误汇总。发现新的错误随时添加。

## 语法类

### 动词时态

| ❌ 错误 | ✅ 正确 | 说明 |
|---------|---------|------|
| I haven't start fix it | I haven't started fixing it | 完成时要用过去分词，start 后面跟 -ing |
| I didn't start fix it | I didn't start fixing it | 否定过去式后跟 -ing |
| I didn't see your message | I didn't see your message | ✅ 这个是对的（常见误以为要用 haven't） |
| I already push the code | I already pushed the code | already 配过去式 |
| Yesterday I work on login | Yesterday I worked on login | 过去时间用过去式 |
| I finish it yesterday | I finished it yesterday | 过去式 |
| You said that yesterday too | ✅ | 这个是对的 |
| I underestimate this problem | I underestimated this problem | 已经发生了要用过去式 |

### 主谓一致

| ❌ 错误 | ✅ 正确 | 说明 |
|---------|---------|------|
| This sprint have too many tasks | This sprint has too many tasks | sprint 是单数，用 has |
| The requirements is not clear | The requirements are not clear | requirements 是复数 |
| Everything are done | Everything is done | everything 是单数 |

### 不可数名词

| ❌ 错误 | ✅ 正确 | 说明 |
|---------|---------|------|
| We can't finish so many works | We can't finish so much work | work 不可数 |
| I have many feedbacks | I have a lot of feedback | feedback 不可数 |
| Some new informations | Some new information | information 不可数 |
| Fewer bugs | ✅ | bugs 可数，fewer 是对的 |

## 词汇/表达类

### 中式直译

| ❌ 错误 | ✅ 正确 | 说明 |
|---------|---------|------|
| I very like this solution | I really like this solution | very 不直接修饰动词 |
| This problem is very trouble | This problem is very troublesome / This is a problem | trouble 是名词 |
| I have a question to ask you | I have a question | "to ask you" 多余 |
| Can you open the computer? | Can you turn on the computer? | open 是打开门/文件 |
| I'm going back to company | I'm going back to the office | company 是公司组织，office 是地点 |
| No why | No reason / Just because | 中式直译 |
| You go first go | You go first | go 重复 |

### 站会常用

| ❌ 错误 | ✅ 正确 | 说明 |
|---------|---------|------|
| I have pushed PR | My PR is up / I put up a PR | "pushed" 是 git 操作，站会不说 |
| I will look at this thing | I'll take a look / I'll check it out | "thing" 太模糊 |
| This is my today's plan | My plan for today is... | 双重所有格 |
| I have a meeting need to join | I have a meeting to attend | 句式错误 |

### 做完了/进度

| ❌ 错误 | ✅ 正确 | 说明 |
|---------|---------|------|
| I'm finish my task | I finished my task | be + 过去分词 ≠ 完成时 |
| I have done it | ✅ | 这个是对的 |
| I've been done | I've done it / I finished | "been done" 是被动语态 |
| I almost finish | I'm almost done | 缺少 be 动词 |
| Still on working | Still working on it | on 和 working 不一起用 |

## AI 相关错误

| ❌ 错误 | ✅ 正确 | 说明 |
|---------|---------|------|
| AI tell me to do this | AI told me to do this / AI suggested this | 过去式 |
| I use AI to wrote this | I used AI to write this | use 和 wrote 时态冲突 |
| AI can't solve | AI can't solve it / AI can't help with this | 缺少宾语 |
| Let AI do it | Let AI handle it / Let AI do it | ✅ "Let AI do it" 是对的 |
