### "I already fixed that. Can you check the latest build?"

QA 提了修过的 bug。

还可以说：
- That should be resolved already
- That fix was deployed yesterday
- Are you on the latest version?
- Can you pull the latest and try again?

### "That's existing behavior"

不是新 bug。

还可以说：
- This was like this before my change
- It's not related to my PR
- This is pre-existing
- File a separate ticket for this one
