### "Can you verify on staging?"
跟 QA 确认修复。
还可以说：
- Can you test it on staging?
- Let me know if it's fixed now
- I deployed the fix, can you verify?
- Confirm on staging before I close the ticket

### "Are you on the latest build?"
版本没更新。
还可以说：
- Did you pull the latest changes?
- You might be testing the old version
- Can you do a hard refresh?
- The fix isn't deployed yet

### "Which one should I prioritize?"
多个 bug 优先级。
还可以说：
- What's the most critical one?
- Which bug is blocking users?
- Should I fix this first or that?
- Give me the priority order
