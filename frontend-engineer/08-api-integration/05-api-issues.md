### "Expecting array but getting object"
数据格式不一致。
还可以说：
- The response format is wrong
- I need an array here but got an object
- The schema doesn't match what we agreed on
- Can you standardize the response format?

### "Getting 401, did the token change?"
认证问题。
还可以说：
- The auth token expired
- I'm getting unauthorized errors
- Did you update the authentication?
- The API key is invalid

### "Are you done with your part?"
对方没准备好。
还可以说：
- Is your side ready?
- When can I start testing?
- I'm blocked waiting for you
- Let me know when it's deployed
