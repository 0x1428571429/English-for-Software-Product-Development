### "The doc is outdated"
文档过期，跟实际接口对不上。

Also say：
- The doc doesn't match the API
- The spec is wrong
- We changed it but forgot to update the doc
- The doc says one thing, the response is different

### "You didn't tell me"
接口改了没通知。

Also say：
- You changed the field names without telling me
- When did this change?
- No one notified me about this
- This broke my integration

### "It times out"
接口超时。

Also say：
- The request is timing out
- It takes too long to respond
- The API is too slow
- 30 seconds is too long

### CORS
- I can't call your API from the frontend
- No CORS header
- Can you whitelist localhost?
- Add my domain to the CORS policy

### "Mock returns different data than the real API"
mock和生产不一致。

Also say：
- The mock is camelCase but the API is snake_case
- The mock was written by someone else
- I spent an hour debugging that mismatch
- Can you keep the mock in sync with production?

### "Can we pair on this?"
联调时两边一起确认。

Also say：
- Let's test it together
- Can you walk me through it?
- I want to make sure it works end to end
- Let's debug this together
