### "It requires a library we don't have"

设计稿用的技术栈做不到。

还可以说：
- We don't have that dependency
- That library isn't in our stack
- We'd need to add a new package
- That animation isn't feasible with CSS alone

### "Can you provide the mobile specs?"

移动端设计稿缺失。

还可以说：
- The mobile version isn't designed yet
- What about tablet?
- How does this look on smaller screens?
- The buttons are too small for touch
